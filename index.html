사용 방법 및 저장 안내

답안 입력 후 Enter를 누르면 다음 문항으로 이동합니다. Shift + Enter로 이전 문항으로 돌아갈 수 있습니다. 40번에서 Enter를 누르면 입력 완료 버튼으로 이동합니다. 한글 조합 중 Enter는 문항을 이동하지 않습니다.

채점 모드에서 각 답안을 누르면 미채점 → 정답 → 오답 → 정답 순으로 바뀝니다. 답안 수정 시 해당 문항의 채점은 초기화됩니다. ‘모두 정답으로’를 누른 후 틀린 문항만 클릭해도 됩니다. 모든 문항을 채점하면 최종 점수가 표시됩니다. 정답표와 직접 비교하는 수동 채점이며 IELTS 밴드 점수는 계산하지 않습니다.

동일한 브라우저에서 동일한 위치의 파일을 열어 사용하세요. 파일 이동, 브라우저 데이터 삭제, 시크릿 모드 또는 브라우저의 로컬 파일 저장 제한으로 기록이 유지되지 않을 수 있습니다. 중요한 기록은 ‘기록 백업’으로 보관하세요. 복제는 답안만 복사하며 채점은 새로 시작합니다.
